# 宇宙／外星意识接触协议 / Cosmic and Alien-Consciousness Contact Protocol

## 中文

## 1. 设计目标

协议既反对人类中心主义，也反对把任何异常、周期性或复杂信号直接拟人化。它扩大生命和意识搜索空间，同时提高证据门槛。

## 2. 六阶段

### D：原始记录

保存原始时间序列、频谱、仪器配置、天区、环境、负结果和数据处理版本。

### I：差异与干扰

比较本地电子设备、卫星、飞机、地面发射源、数据管道和统计选择效应。要求独立站复现。

### K：世界模型竞争

至少同时评估：

1. 仪器或统计伪影；
2. 人为射频干扰；
3. 自然天体物理源；
4. 非意识技术过程；
5. 能动技术信号；
6. 意识通信主体。

“技术信号”和“意识主体”是两个不同结论。

### W：价值与风险

评估误报、社会恐慌、军事化、生态干扰、潜在主体伤害、信息危害和地球代表权。

### P：语义握手

只有在高证据条件和具名授权下，才可考虑低能量、可撤回、非诱骗的挑战—响应。先交换可公开验证的数学／物理结构，再逐步交换目的、边界和意图。

### RETURN：结果回流

响应和无响应都进入账本。预先声明成功、失败和模型退役条件。

## 3. 禁止自动行动

软件不自动发射、不自动联系、不代表人类文明、不隐瞒接触、不绕过停止。外部行动权限恒为0。

## English

The protocol expands the search beyond carbon-brain assumptions while rejecting anomaly-to-agency shortcuts. It moves through raw data (D), interference decomposition (I), non-isomorphic world-model competition (K), ethical and representation constraints (W), explicitly authorized semantic handshake (P), and reality return.

A technosignature is not automatically a conscious communicator. No transmission is automatically authorized.
