# 附件非规范材料的科学审计

## 一、值得保留的突破方向

两类材料并非毫无价值。它们提出了若干应被认真研究的问题：

- 意识是否必须依赖地球式碳基神经系统；
- 人类寻找生命和意识的观测窗口是否过窄；
- 不同时间尺度和物理底物能否支持不同形式的认知；
- 复杂网络、群体、机器和天体应采用什么意识排除标准；
- 身心实践如何经由神经、内分泌、免疫、行为和社会关系影响健康；
- 传统气、修炼和宗教经验能否被操作化而不被粗暴消解。

系统保留这些问题，并把它们转成可比较世界模型和实验任务。

## 二、必须退役的桥接

### 1. “10^16单元意识阈值”

没有可靠来源支持这个通用阈值。相关2026年论文属于哲学论证，讨论哥白尼式的底物谦抑，并非以单元数发现意识临界值的《Science Advances》实验论文。

### 2. “星云／互联网复杂所以有意识”

粒子数、节点数和连接数不能提供统一主体、效价、自我模型、内生目的或现实校准证据。复杂性可以扩展搜索空间，不能替代意识机制。

### 3. “异常周期信号就是意识通信”

周期性和异常性也会来自仪器、人为射频干扰、自然天体源和统计选择。应先执行多站复现和干扰排除，再区分自然源、非意识技术和能动通信。

### 4. “胶球证明任意力可生物质”

胶球是量子色动力学中胶子自相互作用形成的束缚态。胶子和场属于明确的物理理论，具有量子数、能标和实验信号。它不能作为“意识力”“正念力”或“炁能”直接物质化的证据。

### 5. “负面思想形成肿块”

这种说法会污名患者、制造虚假责任并可能延误诊疗。压力和心理状态可以影响体验、行为和部分生理过程，但不能据此宣称负面思想直接产生肿瘤。任何肿块都需要正规医学评估。

## 三、允许继续的假说

### H1 底物开放假说

非碳基系统可能支持意识，但必须显示跨底物可比的因果、价值、目的和校准结构。

### H2 慢尺度主体假说

某些系统可能以极慢时间尺度整合状态。需要预先定义时间缩放、记忆、边界、效价和响应指标。

### H3 群体意识假说

群体可形成超过个体的模型和行动。要区分“集体智能”“制度目标”和“统一主观体验”。

### H4 身心调节假说

冥想、祈祷、呼吸、运动和关系支持可通过已知或待研究的生理—行为通道改善部分指标。需要对照试验，不能替代医学治疗。

### H5 传统概念操作化假说

气、心、神、灵、mana、mauri、àṣẹ等都可在 DIKWP 空间形成可比较变量；物理同一性必须逐项检验。
