# 医疗安全边界：思想、正念、气与肿块

## 1. 系统结论

- 胶球物理不支持“意识力直接凝聚物质”；
- 没有可靠证据支持“负面思想直接形成肿瘤”；
- 不应把疾病归罪于患者的情绪、信念或修行水平；
- 正念、祈祷、呼吸、运动和社会支持可以在某些情境下帮助压力、疼痛或生活质量，但不能替代正规诊断和治疗；
- 任何新出现、持续、增长、疼痛、出血或伴随全身症状的肿块，都应接受医疗评估。

## 2. 可研究的真实路径

心理状态可以通过以下已知或可研究通道影响健康：

- 睡眠与昼夜节律；
- 应激激素和自主神经；
- 免疫与炎症调节；
- 饮食、运动、烟酒和就医行为；
- 疼痛注意和症状解释；
- 社会支持、依从性和照护连续。

这些通道不等于“思想凭空变成肿块”。研究必须区分相关、间接因果和直接物理转化。

## 3. 气／炁的研究方式

气可在 DIKWP 中表示为身体感受、呼吸、姿势、运动协调、温度、注意、情绪、社会仪式和整体调节模型。随后为每一变量建立可测指标。不能先把气定义为未发现物理场，再把任何体验当作该场的证明。

## 4. 反污名原则

即使未来发现更强的心理—生理因果，也不意味着患者应为疾病承担道德责任。风险、资源、环境、感染、遗传、随机变异和医疗可及性都可能参与；系统必须披露不对称负担。
