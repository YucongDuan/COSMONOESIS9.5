# Release Notes — DIKWP-COSMONOESIS 9.5 v1.0.0

This release establishes a unified DIKWP coordinate system for religious, civilizational, scientific and philosophical concepts. It deliberately distinguishes coordinate normalization from doctrinal equivalence. It also replaces single-threshold consciousness claims with multi-theory, multi-dimensional evidence assessment and explicit reality-return requirements.

The bundled demonstration audits the supplied viral-style claims about alien consciousness and glueballs. It preserves the valuable substrate-open and anti-anthropocentric questions while rejecting unsupported numerical thresholds, unexplained-signal agency attribution, and medical claims that blame tumors on negative thought.

All external action remains human-authorized and revocable; automatic external-action authority is 0.
- Bundle content digests are now stable across equivalent recompilations because `generated_at` is excluded by an explicit digest policy.
